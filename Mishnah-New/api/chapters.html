Every Chapter in the Structured Mishnah API

This page lists every file the API serves: the four top-level files, all 63 tractate files, and all 525 chapter files, grouped by the six orders of the Mishnah. It exists so that a reader, a search engine or a research tool can reach any chapter directly, without having to guess an address. The documentation is on the main API page.

The four top-level files

  • index.json — counts, the six orders, and all 63 tractates
  • tractates.json — the 63 tractates as a flat list
  • markers.json — the eight marker types, with colour and definition
  • schema.json — every field of a chapter file, described

About Moshe Kline

Graduate of St. John's College and Yeshiva University. Studied under Jacob Klein, influenced by Leo Strauss. Later studied with Rabbi Leon Ashkenazi ("Manitou"). Mentored by Jacob Milgrom and Mary Douglas.

The Woven Torah methodology has been independently validated in a PhD thesis by Paul Hocking (University of Chester, 2021), supervised by Philip Alexander (University of Manchester). The literary structure of Leviticus was verified by Jacob Milgrom and published by David Noel Freedman.
