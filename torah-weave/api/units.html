Every Unit in the Structured Torah API

This page lists every file the API serves: the five top-level files, all 5 book files, and all 86 unit files, grouped by book. It exists so that a reader, a search engine or a research tool can reach any unit directly, without having to guess an address. The documentation is on the main API page.

The five top-level files

  • index.json — counts, the five books, and all 86 units
  • books.json — the five books as a flat list
  • markers.json — the eight marker types, with colour and definition
  • schema.json — every field of a unit file, described
  • discrepancies.json — where this data differs from the Torah Units Dataset

About Moshe Kline

Graduate of St. John's College and Yeshiva University. Studied under Jacob Klein, influenced by Leo Strauss. Later studied with Rabbi Leon Ashkenazi ("Manitou"). Mentored by Jacob Milgrom and Mary Douglas.

The Woven Torah methodology has been independently validated in a PhD thesis by Paul Hocking (University of Chester, 2021), supervised by Philip Alexander (University of Manchester). The literary structure of Leviticus was verified by Jacob Milgrom and published by David Noel Freedman.
