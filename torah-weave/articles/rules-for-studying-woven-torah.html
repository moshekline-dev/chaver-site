Rules for Studying the Woven Torah

Master the Art of Two-Dimensional Biblical Reading

Discover the Hidden Architecture

On this site, you'll find the Torah's 86 units presented in their woven form—arranged in tables that reveal their two-dimensional structure. The columns, color coding, and parallel arrangements are already provided.

These rules teach you how to read these structured presentations to discover meanings that remain invisible in traditional linear reading. Think of yourself as viewing a tapestry that's already been woven. Your task is to learn how to see the patterns, understand what the colors signify, and perceive how the intersecting threads create meaning.

Understanding the Marking System

Warp Threads (Columns)

Marked with uppercase letters

A, B, C, D...

Each column follows a vertical organizing principle

Weft Threads (Rows)

Marked with numbers

1, 2, 3, 4, 5...

Each row follows a horizontal organizing principle

Cell Reference

Row + Column notation

2B = Row 2, Column B

The intersection of weft thread 2 and warp thread B

Sub-sections within cells: Sometimes marked with lowercase letters (a, b, c...) when a single cell contains multiple segments. For example, "3a-c" refers to subsections a through c within Row 3.

The Ten Rules for Reading Woven Torah Units

1

Recognize the Table Structure

Each unit is presented as a table with specific dimensions. Note how many columns (A, B, C...) and rows (1, 2, 3...) organize the text. This structure is not arbitrary—it reveals the unit's meaning.

Example

Genesis Unit 1 has 2 columns × 3 rows. Column A contains Days 1-3 (creating realms), Column B contains Days 4-6 (filling those realms). The structure itself teaches that creation has two complementary phases.

2

Read Parallel Positions

Elements in the same row are meant to be read together. The table alignment shows you which passages illuminate each other.

Example

In Genesis Unit 1, Row 1 pairs Day 1 (light creation) with Day 4 (light sources). Row 2 pairs Day 2 (sky/water separation) with Day 5 (sky/water creatures). The parallels are deliberate and meaningful.

3

Follow the Color Coding

Colors highlight verbal and thematic connections across the text. When you see the same color in different cells, trace the connection. Use "Show Color Legend" to decode the highlighting.

Example

Blue often marks "horizontal parallels" (same-row connections). Gold marks "vertical parallels" (same-column connections). Pink indicates "closure" elements that frame the unit.

4

Read Down Columns (Warp Threads)

Each column follows one continuous theme or progression. Reading down reveals how that theme develops through the unit.

Example

In Exodus Unit 3: Column A shows all signs with morning confrontation. Column B shows court appearances. Column C shows unannounced signs. Each column represents a different approach to Pharaoh.

5

Read Across Rows (Weft Threads)

Each row typically groups related elements or shows progression. Reading across reveals how different aspects interact.

Example

In Exodus Unit 3: Row 2 = Aaron performs (blood, frogs, lice). Row 3 = mixed agency. Row 4 = Moses performs (hail, locusts, darkness). The progression shows increasing directness of divine action.

6

Find Meaning at Intersections

Each cell's content is determined by BOTH its column theme AND its row theme. Ask: Why does THIS content appear at THIS intersection?

Example

Cell 4C (Darkness) combines Moses's agency (Row 4) with no warning (Column C). The most direct divine agent + most abrupt approach = most severe sign.

7

Track Divine Name Patterns

Notice which divine name appears where: YHWH, Elohim, El Shaddai, etc. The distribution often aligns with the unit's structure and message.

Example

Units using only "Elohim" often deal with natural order. Units using only "YHWH" often involve supernatural intervention. Mixed usage may show the interaction between these aspects.

8

Identify Special Positions

Certain positions carry extra weight: center (in odd-numbered structures), corners, and envelope positions (first/last rows or columns).

Example

In 5-row structures, Row 3 often contains the core message. In Leviticus 19's five pairs, the central pair addresses love and justice—the heart of holiness.

9

Recognize Structural Patterns

Common patterns include: progressive intensification, chiastic (mirror) arrangements, envelope structures, and concentric designs. The pattern shapes meaning.

Example

Exodus Unit 3 shows intensification: annoyances (Row 2) → economic damage (Row 3) → catastrophes (Row 4). Plus inversion: earth-origin signs above, sky-origin below—world turned upside down.

10

Let Structure Reveal Theology

The deepest insights emerge when you ask: What does this structure teach about the divine, humanity, or their relationship? Form carries meaning.

Example

The Creation structure (realms → inhabitants) reveals a theology of order and purpose. The inverted plague structure reveals YHWH's power to overturn that very order.

How to Approach a Unit Page

1

First Pass

Read the introduction to understand context and boundaries

2

Survey Structure

Note the table dimensions and organizing principles

3

Linear Reading

Read through naturally first (use "Show Verse Numbers" if helpful)

4

Structural Reading

Read by columns, then by rows, noting patterns

5

Apply the Rules

Work through Rules 3-10 to discover deeper meanings

Practical Tips

  • Start with units that have completed commentaries to learn the method
  • Use colored highlighting to track different themes or divine names
  • Draw your own diagrams to internalize the structures
  • Study with others—different perspectives reveal different patterns
  • Return to units multiple times—new insights emerge with familiarity
  • Keep a journal of structural patterns you discover across units
