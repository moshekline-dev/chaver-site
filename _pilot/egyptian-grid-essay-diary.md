## 2. Standing Rules (Moshe's binding corrections)

1. YHWH/Elohim row distribution is Genesis-specific. Beyond Genesis, rows carry ORIENTATION (deity-oriented / interface / people-oriented), not divine names.
2. Divine-name criterion is dramatic and unit-level: ONSTAGE = narrator presents the deity acting/speaking; OFFSTAGE = a character mentions the deity. Names in characters' speech do not count.
3. The Ra-Osiris/Amduat parallel is a COMPOSITIONAL PARADIGM ONLY — never theological equivalence. Amduat union is automatic/cosmic; Torah union is commanded, requires human action.
4. Literary analysis only. NO DARSHANUT. The test (fixed 2026-06-10): an observation is reasoning if both of its terms are verifiable formal facts of the composition and the claim is only that they coincide; it is darshanut if it assigns a figure a referent outside the text (Israel, the soul, etc.). Connect, never import. The voice attributed to the Ark is the voice of YHWH.
5. Read sources IN FULL, never from summaries. Never state structural claims (pairings, formats, coordinates) from memory — verify against source files or live pages, or ask Moshe.
6. Prohibited vocabulary in Claude's own voice: salvation, theological, profound, remarkable, striking, extraordinary, crucial, critical, essential, vital, transforms, revolutionary, radical, significant (evaluative), hidden, secret, generic "God". Use: YHWH, Elohim, "deity"; deliverance/rescue/preservation; embedded/structural. (Published title "Structure is Theology" exempt.)
7. Notation: rows = Arabic numerals; columns = UPPERCASE letters; subdivisions = lowercase. BCV internal notation: weft threads 1,2,3; segments א,ב,ג; elements A,B; parts i,ii. Beautiful Weave notation: pairs 1–5, rows A/B, columns L/M/R, segments e.g. 5LB.
